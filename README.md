## How DMIT Promo Codes Actually Work

Before pasting any code, it helps to understand DMIT's discount system, because it's not the typical "10% off everything" model.

**Codes are product-line specific.** A promo code is almost always tied to a particular network series (Premium, Eyeball, or Tier 1), a particular location (LAX, HKG, TYO, SJC), and sometimes a particular plan tier or higher. The code `LAX-EB-LAUNCH-NON-MONTHLY-RECURRING-20OFF` only applies to LAX Eyeball TINY and above; it won't work on a Hong Kong plan or on a LAX Premium plan.

**Most codes require non-monthly billing.** The "NON-MONTHLY-RECURRING" or "ANNUALLY" in many code names is literal. Monthly billing almost never qualifies for the bigger discounts. If you're committed to monthly, expect to pay full price or settle for the rare monthly-eligible code like `2025-TYO-T1-HI-GSL-MONTHLY-10OFF`.

**"Recurring" means the discount repeats.** When a code says "RECURRING-20OFF" or "45OFF-RECUR", the discount applies on every renewal, not just the first invoice. This is genuinely valuable — a 20% recurring discount on a $29.90/mo plan saves you about $71.76/year, every year, for as long as you keep the service.

**Some codes stack with account credit cashback.** The 2025 Christmas codes (e.g., `2025-XMAS-LAX-T1-ANNUALLY-EXCL-WEE-TINY-20OFF-RECURRING`) combined a recurring discount with a 5–10% account credit cashback, settled monthly. The Christmas event page itself shows "has ended," so treat those as historical unless DMIT revives them.

**Codes generally only apply to new customers.** DMIT's own Terms of Service state: "Discount codes only apply to new customers." Existing customers sometimes receive compensation codes for service issues, but you can't stack a public promo code onto an existing subscription.

## Where to Apply the Code at Checkout

The promo code field is on the order confirmation page, not the plan selection page. The flow:

1. Pick a location and network series on the cloud instance page.
2. Click Order Now on the plan you want.
3. Select your billing cycle (monthly, quarterly, semi-annually, annually). This matters — most codes only activate on quarterly or longer.
4. On the checkout page, look for the field labeled "Promo Code" or "Coupon Code." It's smaller than you'd expect.
5. Paste the code, click Apply, and confirm the line item discount appears before completing payment.

If the code returns an error, the most common reasons are: wrong product line (e.g., an EB code on a Pro plan), wrong billing cycle (monthly on a non-monthly code), or a plan tier below the code's minimum (e.g., a "STARTER and higher" code on a WEE or TINY plan). DMIT doesn't always surface a helpful error message, so cross-reference the code's stated applicability before assuming it's dead.

## Things to Watch Out For

A few realities of buying DMIT with promo codes that aren't always obvious:

**Refund rules tighten on discounted orders.** DMIT's standard policy is a full refund within 3 days (up to 30GB transfer) and a prorated refund within 30 days. But promotion-specific terms often override this — the HKG Tier 1 v2 promotion explicitly stated "the general refund rule does not apply to products purchased at the event price once the service is activated," and the Christmas 2025 event limited refunds to 25 days from purchase with no renewal refunds.

**Discounted plans don't carry the full SLA.** The HKG.T1.WEEv2 and the v2 alpha-test plans explicitly come with no SLA guarantee for data loss or IO interruptions. DMIT's standard SLA is 99% uptime with compensation credits if it drops below, but alpha/promotional platforms are excluded.

**IP replacement costs vary by series.** On Premium and Eyeball, free IP replacement every 15 days (or every 7 days with IP Care+). On Tier 1 without the IP Guarantee+ addon, DMIT doesn't guarantee the IP is globally accessible, especially in China/Russia/censored regions, and replacement costs $5 each. If you're buying a Tier 1 plan expecting to use it as a China-facing proxy, you're buying the wrong product.

**Codes can stop working without notice.** DMIT's Terms of Service reserve the right to change pricing and promotions at any time. A code that worked yesterday may return an error today, and DMIT doesn't always publish an expiry date on the code itself. The reliable approach: paste the code at checkout, confirm the discount line item appears, and only then complete payment.
